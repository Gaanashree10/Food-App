# Food-App

## UI/UX Design Project

A mobile food-ordering app designed to make it easy for users to browse food items, add items to cart, and place orders.

### My Role
UI/UX Designer

### Tools
- Figma
- Wireframing
- Prototyping
- UI Design

### Key Features
- Restaurant and food discovery
- Search and categories
- Food details
- Add to cart
- Checkout and payment
- Order tracking
